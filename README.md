# Дайсхолл (Dicehall)

Виртуальный стол для онлайн-партий D&D 5e. Electron + встроенный сервер на Node (`ws`), 3D-стол на three.js.
Мастер запускает приложение и поднимает стол, игроки подключаются по адресу (Radmin VPN, Hamachi, ZeroTier, Tailscale
или локальная сеть), в том числе из обычного браузера.

Текущая версия: **0.32.0**. Подробная история версий и правила: [docs/ЗАПУСК.txt](docs/ЗАПУСК.txt).

## Запуск из исходников

Нужен Node.js.

```bash
npm install
npm start          # приложение Electron
npm run server     # только сервер, без окна (порт 7777, токен мастера печатается в консоль)
npm run pack       # сборка для Windows x64 в release/
```

## Структура

| Путь | Что это |
|---|---|
| `main.js`, `preload.js` | главный процесс Electron, IPC `host:start`, `host:saved`, окно 1920×1080 с масштабом |
| `server.js` | http + WebSocket сервер: состояние стола, бои, сцены, звук, загрузка `.glb` и треков, автосохранение в `table.json` |
| `src/grid.cjs`, `src/tplgeom.cjs` | геометрия сетки (квадраты, гексы) и попадание в шаблоны заклинаний, общий код сервера и клиента |
| `dist/` | **собранный** клиент (`app.js`, esbuild), `index.html`, `style.css` |
| `docs/` | справка по запуску и changelog, источники иконок и 3D-моделей |

## Важно

- В репозитории только собранный бандл клиента `dist/app.js`. Исходники клиента (до сборки) сюда не входят.
- Шрифты (`dist/fonts/`) не хранятся в репозитории: Mookmania, Volbera и Nodesto из сообщества Pathfinder, их лицензии не разрешают раздачу.
  Положите свои файлы в `dist/fonts/`, иначе интерфейс покажет запасные шрифты.
- Скрипты `start`, `server`, `pack` и dev-зависимости восстановлены по документации, в упакованном `app.asar` их не было. `pack` не проверялся.
- Папка `Dicehall-win32-x64/` содержит часть бинарников Electron, загруженных вручную. В сборку она не входит.
