ДАЙСХОЛЛ — виртуальный стол для D&D 5e (этап 2)

ЗАПУСК
  Распакуйте архив целиком и запустите Dicehall.exe. Установка не нужна.
  Windows может показать предупреждение SmartScreen (приложение без подписи):
  «Подробнее» → «Выполнить в любом случае».

КАК ИГРАТЬ ВМЕСТЕ
  1. Все участники заходят в одну сеть Radmin VPN или Hamachi
     (в одной квартире/локальной сети VPN не нужен).
  2. Мастер: «Создать стол» → «Открыть стол». При первом запуске Windows спросит
     про доступ к сети — разрешите. Вверху появится «Адрес для игроков».
  3. Игроки: «Подключиться» → вставить адрес мастера (например 26.10.20.30:7777).
     Без приложения можно зайти из браузера: http://адрес:7777

БРОСКИ
  Кости внизу: клик — добавить, правый клик — убрать. В чате: /r 2к6+3
  На листе персонажа: клик по модификатору, навыку, спасброску, атаке.
  Shift+клик — преимущество, Ctrl+клик — помеха, Shift+«Урон» — критический.
  Мастеру доступен скрытый бросок.

СТОЛ
  Приложение открывается на весь экран (рассчитано на 1920×1080, на других
  экранах масштабируется). F11 — оконный режим.
  Колесо мыши — приближение, перетаскивание пустого места — сдвиг стола,
  Alt + перетаскивание (или колесо-кнопка) — поворот камеры, «Весь стол» — сброс.
  Стол изначально пустой. Мастер: «Положить карту» кладёт картинку на сукно —
  её можно двигать мышью, менять размер (− / +), закрепить или убрать; карт может
  быть несколько. «Фишка врага» выставляет фишки, «Размер фигур» подгоняет фигурки под клетку карты.
  Игрок: «Поставить миниатюру» — фигурка своего класса. Фигуры двигаются мышью,
  Q/E — поворот, Delete — убрать. Игрок двигает только свою фигурку, мастер — все.

ЛИСТ ПЕРСОНАЖА
  Стопка листов лежит в левом нижнем углу стола. Клик открывает страницу крупно:
  лист, заметки, заклинания, дополнительная. Esc — убрать в стопку.

ГДЕ ХРАНЯТСЯ ПЕРСОНАЖИ
  На компьютере каждого игрока. «Экспорт» сохраняет героя в файл,
  «Импорт из файла» переносит его на другой компьютер.

ДЛЯ РАЗРАБОТКИ (архив с исходниками)
  Нужен Node.js. В папке проекта: npm install, затем npm start.
  Сборка для Windows: npm run pack

СОХРАНЕНИЕ (0.3)
Стол мастера (карты, фигуры, журнал, места игроков) сохраняется автоматически в файл table.json в папке данных приложения (%APPDATA%\Дайсхолл или Dicehall). При следующем «Создать стол» приложение предложит «Продолжить» или «Начать заново».

БИБЛИОТЕКА (0.4)
Кнопка «Библиотека» есть в главном меню и на столе. Вкладки: заклинания (319), бестиарий (334), магические предметы (362), снаряжение (237), состояния, черты, «Мои записи».
Данные — SRD 5.1 (Wizards of the Coast, CC-BY-4.0) в виде базы 5e-database (MIT), тексты на английском. Свои записи, переводы и материалы из других книг добавляйте во вкладке «Мои записи» (есть импорт и экспорт JSON).
В карточках кубы вида 2d6+3 и «+5 to hit» — кнопки: клик бросает кость для всех за столом. Заклинание можно добавить в лист активного персонажа, монстра — выставить фишкой на стол (мастер).

ПЕРЕВОД БИБЛИОТЕКИ (0.4.2)
Библиотека переведена на русский полностью: 319 заклинаний, 334 монстра с умениями, 362 магических предмета, всё снаряжение, состояния. Перевод авторский, по SRD 5.1 (CC-BY-4.0). Кнопка «RU · показать английский» в библиотеке переключает язык.


КАМПАНИИ И СЦЕНЫ (0.5.0)
У мастера наверху кнопка «Кампания · Сцена»: назвать кампанию, создать сцену, переключаться между сценами, делать копию, переименовывать, удалять. У каждой сцены свои карты и фишки. Игроки видят переключение сразу, их фигурки переходят вместе с ними. Всё сохраняется вместе со столом; старые сохранения открываются как «Сцена 1».

СЕТКА И ПЕРЕМЕЩЕНИЕ (0.6.0)
- Кнопка «Сетка» (мастер): квадраты, гексы (остриём вверх или плоской стороной), размер клетки, футов в клетке, диагонали 5 фт. или 5-10-5, цвет и яркость линий.
- Если на карте уже есть своя сетка: «Подогнать по двум точкам» (кликните два узла сетки, укажите число клеток между ними; у гексов - центры двух соседних гексов) или вручную размер + «Сдвинуть сетку мышью».
- Фигуры всегда стоят в клетках. Большие существа занимают 2x2, 3x3, 4x4 (размер задаётся у фишки или при выставлении врага).
- Выберите фигуру: зелёная зона = дойдёт шагом, жёлтая = рывок (двойная скорость). При перетаскивании виден путь и цена в футах. Скорость и «пройдено» видны в панели фигуры; «Новый ход» и «Новый ход всем» сбрасывают.
- Игроки не могут уйти дальше зоны хода; мастер двигает свободно (Shift при отпускании = без списания хода).
- Местность (слева от стола, мастер): труднопроходимая (x2), преграда, стена, низкая стена (+1 клетка), дверь (клик открывает/закрывает), ластик. Линейка: клавиша R, Esc - выбор.
- Шаблоны заклинаний (конус, сфера, линия, куб) будут в следующей версии.

БОЙ (0.7.0)
- Панель «Бой» справа от стола. «Начать бой» (мастер) бросает инициативу всем фишкам (d20 + Ловкость; у героев берётся из листа, у монстров из характеристик). Число инициативы в списке можно поправить, у кого её нет - не участвует.
- Зелёное кольцо под фигурой показывает, чей сейчас ход. «Следующий ход» / «Назад» двигают очередь и счётчик раундов; игрок в свой ход видит кнопку «Закончить ход». Ход новой фигуры начинается с нулевым пройденным расстоянием.
- В бою игрок может двигать свою фигуру только в свой ход (мастер - всегда). Фишки врагов с 0 хитов пропускаются.
- Хиты: в панели выбранной фигуры (хиты / максимум, поле + «Урон» / «Лечение»). Над фигурой полоска хитов; игроки видят её только у героев, у врагов её видит мастер. Хиты героя синхронизируются с его листом персонажа в обе стороны.
- Состояния: кнопка «Состояния» (15 состояний 5e + концентрация): фиолетовые значки над фигурой и в списке боя.
- Враги из библиотеки (кнопка «На стол») и из формы «Фишка врага» получают хиты, скорость и размер автоматически.

ПЕРЕХОДЫ И РЕЖИМЫ (0.8.0)
- Режим «Свободно» / «По ходам» (переключатель над инструментами, мастер): свободно - фигурки ставятся в любые клетки без счёта шагов и зон хода (для путешествий); по ходам - скорость, зона хода и пройденное расстояние. Бой включает режим «По ходам» сам и после боя возвращает прежний. Режим у каждой сцены свой.
- Переход: инструмент «Переход» - растяните прямоугольник на карте (например, на дом), выберите, куда ведёт (новая пустая сцена или существующая), закрыт ли он (с подсказкой для игроков), скрыт ли, и нужен ли обратный «Выход». Игрок нажимает на переход (его фигурка должна быть рядом) и попадает в ту сцену один; остальные его не видят и ничего не теряют. Закрытый переход не пускает: открыть его можете вы (клик по переходу -> «Закрыто / Открыто»), например после броска игрока.
- «Сцена» -> щелчок по сцене переводит мастера и всех; «Только мне» - заглянуть в сцену без игроков; «Позвать всех сюда» собирает игроков в вашу сцену. В списке сцен видно, кто где находится.

3D-ФИГУРКИ (0.8.1)
- Фигурки игроков теперь настоящие 3D-модели на все 12 классов (KayKit, CC0), см. МОДЕЛИ-3D.txt. Размер подгоняется под клетку (после калибровки сетки).

СВОИ СУЩЕСТВА И NPC (0.9.0)
- Библиотека -> «Мои существа»: полноценный редактор статблока (размер, тип, КД, хиты и кости с авторасчётом среднего, 6 характеристик с модификаторами, спасброски, навыки, сопротивления, чувства, языки, ОП с опытом и бонусом, особенности, действия, реакции, легендарные действия, заметки мастера). Кнопка «+ Атака» подставляет заготовку с вашими бонусами. Кубы в тексте становятся кнопками броска.
- «Бестиарий» -> любая карточка -> «В мои существа (править копию)»: берёт SRD-монстра (с русским переводом) и открывает его в редакторе: усилить, ослабить, переименовать, сделать NPC.
- Из «Моих существ» можно сразу поставить фишку на стол (хиты, КД, скорость, размер и бонус инициативы подтягиваются сами). NPC помечаются галочкой и фишкой-человечком.
- Хранятся на этом компьютере. Экспорт/импорт в JSON - чтобы переносить между компьютерами и делиться.

ЭНКАУНТЕРЫ (0.10.0)
- Библиотека -> «Энкаунтеры»: соберите встречу заранее. Ищете существо по названию (свои и из Бестиария), задаёте количество кнопками − / +.
- Сложность считается по правилам DMG: опыт существ с множителем за численность против порогов вашей партии (укажите число героев и уровень). Показаны пороги: лёгкая / средняя / трудная / смертельная.
- «Выставить всех на стол» ставит фишки всех существ сразу, с номерами у одинаковых (Гоблин 1, 2, 3), с хитами, КД, скоростью и бонусом инициативы. Дальше «Начать бой». Встречи хранятся на этом компьютере, есть заметки и копирование.

ИКОНКИ И КАРТИНКИ СУЩЕСТВ (0.10.1)
- Фишка любого существа из Бестиария получает значок по названию и типу (гоблин, скелет, волк, дракон, дьявол, голем, паук, элементаль и т.д.), у остальных - значок по типу существа.
- У своих существ: поле «Значок» (любой эмодзи) и кнопка «Картинка…» - ваше изображение (портрет, арт, скриншот) обрезается кругом и ложится на фишку. Картинки из интернета в программу не вшиты: права на официальные иллюстрации принадлежат издателю, поэтому свои картинки добавляете вы.

МАТЕРИАЛЫ: ПИСЬМА И РЕПЛИКИ NPC (0.11.0)
- Кнопка «Материалы» вверху. У мастера: «Заготовки» - создайте заранее «Письмо / записку» (заголовок, текст, картинка) или «Реплику NPC» (имя, значок или портрет, текст) и нажимайте «Показать» в нужный момент. Можно отметить, кому показать (по умолчанию всем).
- Письмо открывается у игроков на весь экран на старой бумаге (закрывается кнопкой или Esc). Реплика появляется внизу окошком с портретом, текст печатается по буквам; клик показывает весь текст, ещё клик закрывает. Мастер может «Скрыть у всех».
- Всё показанное сохраняется у игроков во вкладке «Показанное» - письмо можно открыть повторно. В журнале остаётся строка, что мастер показал материал.

ТУМАН ВОЙНЫ, СКРЫТЫЕ ФИШКИ, УКАЗКА (0.12.0)
- Туман: слева под инструментами кнопка «Туман: вкл/выкл». «Всё скрыть» закрывает весь стол, потом инструментом «Открыть туман» растягиваете прямоугольники там, куда зашли герои (по клеткам, если сетка калибрована). «Закрыть туман» возвращает тьму, «Всё открыть» снимает её целиком. Мастер видит туман полупрозрачным и всё под ним. У каждой сцены свой туман. Фишки врагов в закрытой области игроки не видят; фигурки героев видны всегда.
- Скрытые фишки: выберите фишку -> «Скрыть». Игроки её не видят, у мастера над ней подпись «скрыт от игроков». Подходит для засады и невидимых существ.
- Указка: Shift + щелчок по столу (у мастера и у игроков) показывает всем в сцене расходящееся кольцо цвета игрока. Удобно сказать «вот сюда» без слов.
- Честно: скрытие работает на экране игрока, но данные о скрытых фишках и тумане всё же доходят до его программы. Для игры с друзьями этого достаточно, от злонамеренного хитреца это не защита.


=== Версия 0.13.0 — повышение уровня и опыт ===
• У игрока, когда опыта хватает на следующий уровень (таблица правил 5e) или мастер разрешил повышение, в верхней панели мигает зелёная кнопка «↑ Уровень».
• Окно повышения: хиты (среднее или бросок кости; рост ТЕЛ даёт хиты и за прошлые уровни), подкласс на нужном уровне, +2 / +1 и +1 к характеристикам или черта (на уровнях 4, 8, 12, 16, 19; у воина и плута больше), новые заговоры и заклинания из библиотеки (с русскими названиями), новые умения класса и таблица «было → стало»: хиты, бонус мастерства, характеристики, спасброски, Сл./атака заклинаний, ячейки.
• Мастер: кнопка «Опыт» — выдать опыт выбранным игрокам или разрешить им повысить уровень вне зависимости от опыта. Опыт игрока также правится на листе.
• Честно: умения классов записываются коротким перечнем названий в «Умения и особенности» (полные тексты — в Руководстве игрока); список черт — 25 популярных, с кратким описанием; подклассы — по несколько основных вариантов, можно вписать свой. Мультиклассирования нет. Окно проверено на 3→4 уровне волшебника и с чертой «Крепкий»; мигающая кнопка и выдача опыта между двумя настоящими клиентами не проверялись.


=== Версия 0.14.0 — панель героя, инвентарь, «О персонаже» ===
• Справа внизу у игрока: большой арт героя и четыре кнопки — «Инвентарь», «Заметки», «Характеристики», «О персонаже». Когда можно повысить уровень, «О персонаже» мигает золотой стрелкой ⬆. Арт: нажмите на него и выберите прозрачный PNG (бюст героя); без него показывается фото персонажа.
• Инвентарь как в Baldur's Gate: слева арт героя и 11 слотов экипировки (голова, шея, плащ, доспех, руки, обувь, 2 кольца, оружие, вторая рука, дальний бой) и характеристики; справа поиск, фильтры (оружие, доспехи, зелья, свитки, прочее), сетка предметов, вес/грузоподъёмность (15 × СИЛ) и деньги. Двойной клик — надеть или снять. Предметы добавляются из библиотеки (снаряжение и магические предметы, названия по-русски) или вручную.
• «О персонаже»: арт, раса/класс/уровень, полоса опыта, умения и предыстория, кнопка «Повысить уровень».
• Мастер: кнопка «Предмет» — выдать вещь выбранным игрокам; она появится у них в инвентаре.
• Акценты повышения уровня и новой панели — золотые.
• Честно: инвентарь и арт хранятся только у игрока и мастеру не видны. Слоты подбираются по названию предмета автоматически (бывают промахи — слот можно не использовать, просто носить в рюкзаке). Эффекты предметов (КЗ, бонусы) на лист сами не переносятся. Панель и окна проверены на тестовой странице; положение панели относительно кубиков и журнала на живом столе у игрока не проверялось, как и выдача предметов между двумя клиентами.


=== Версия 0.15.0 — пак иконок в стиле D&D ===
• Встроено около 750 иконок Game-icons.net (CC BY 3.0, авторство — в файле ИКОНКИ.txt): оружие, доспехи, украшения, расходники, снаряжение, магия, существа, интерфейс. Рисуются векторно, цвет подстраивается под тему.
• Где используются: панель героя и инвентарь (слоты, предметы), фишки врагов на столе (значок дракона, призрака, волка и т.д. вместо эмодзи), список значков фишки врага (теперь 24 вместо 8), существа в энкаунтерах и редакторе, реплики NPC.
• В инвентаре у предмета есть кнопка «Значок» — выбор из набора по категориям.
• Честно: набор — готовый, а не нарисованный мной; в нём бывают странные иконки, часть названий подобрана автоматически. У фишек замена работает для значков из списка и для существ (эмодзи подменяются на иконку, если подходящая есть). Редактор своих существ и реплики NPC по-прежнему принимают эмодзи — они отображаются иконкой, если есть соответствие. Не проверялось на Windows.


=== Версия 0.15.1 — инвентарь и арт видны всем ===

═══ 0.26.0 — урон, смерть, концентрация, состояния ═══
УРОН: на листе рядом с «− урон» выпадающий «вид» урона. Сопротивление (½), иммунитет (0), уязвимость (×2) считаются
  автоматически; настраиваются в панели «Действия» → «Состояния и сопротивления» (нажатие по виду урона: ½ → ∅ → ×2 → нет).
  Ярость (кнопка ○ у ресурса «Ярость») даёт сопротивление дробящему/колющему/рубящему; снимается длинным отдыхом.
  Временные хиты поглощаются первыми. Результат пишется в чат.
СМЕРТЬ: при 0 хитов герой падает без сознания (состояния «без сознания», «лежит»). Урон при 0 хитов = провал спасброска от
  смерти; урон ≥ максимума хитов (в т.ч. остаток после падения) = мгновенная смерть. Бросок «Спасбросок от смерти»
  обрабатывается автоматически: 10+ успех, 1–9 провал, 1 = два провала, 20 = встаёт с 1 хитом; три успеха — стабилизация,
  три провала — гибель. Лечение сбрасывает счётчики и снимает «без сознания». Погибшего можно воскресить кнопкой.
  Критический удар по лежащему (2 провала) — отметьте вручную.
КОНЦЕНТРАЦИЯ: заклинание с концентрацией записывается как текущая; новое прерывает старое. Любой урон автоматически бросает
  спасбросок Телосложения, СЛ = больше из 10 и половины урона; провал — концентрация теряется. Падение на 0 хитов — сразу
  теряется. Кнопка «Прервать» в панели «Действия».
СОСТОЯНИЯ (14 штук, панель «Действия»): влияют на броски: помеха на атаки (ослеплён, испуган, отравлен, лежит, опутан),
  на проверки (испуган, отравлен), на спасбросок Ловкости (опутан); автопровал спасбросков Силы/Ловкости (парализован,
  окаменел, ошеломлён, без сознания); невидимость — преимущество на атаки. Учитываются и состояния с фишки на столе.
  Состояния героя и «концентрируется» синхронизируются со значками на его фишке. Недееспособный не может колдовать и
  получает предупреждение при действиях.
ЧЕСТНО: преимущество для атакующих по вам (парализован, лежит и т.п.), крит с 5 фт. по парализованному, скорость 0, «видимость»
  и источник страха — только текст-подсказки, ГМ учитывает сам. Спасбросок концентрации не учитывает Warcaster/ Стойкость.
  Автопровал выводится в чат без броска. Не проверено: сборка под Windows (я её не запускал), автопроверка в UI двумя
  клиентами — только юнит-тесты правил.
